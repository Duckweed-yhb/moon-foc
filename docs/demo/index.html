moon-foc 浏览器演示

曲线不是截图，是页面加载时由 web_demo.js（MoonBit js 后端产物）逐拍算出来的： 电流环 PI、速度 PI、机械方程、弱磁给定都来自库里的同一个函数。
参数面板用的是预计算网格 - 构建时把每一档都算完，滑块只切档，不在浏览器里实时求解 （MoonBit 的 js 产物没有向外导出函数，页面拿不到句柄）。滑块选中的那一档就是库按那组参数跑出来的原样结果。

级联结构：速度 PI 出 iq 给定，电流 PI 出 d/q 电压（只补反电动势前馈），电气模型步进后算电磁转矩，再推进机械方程。

速度环：iq 给定

受 ±8 A 限幅，稳态值由负载与阻尼决定
iq 给定 ±8 A 限幅

启动段 iq 顶到限幅，进入稳态后落在 3.5 A 附近（1 N·m 负载）：Kt = 0.3 N·m/A，再加上阻尼项。负载拉到最大档时 iq 一直贴着 8 A 也补不上转矩，转速会一路滑下去。

flux_headroom，单位韦伯，跟随上方 iq 档

余量过零的那一点就是基速；此前 id 保持 0，此后按 headroom / Ld 分配负 d 轴电流。iq 越大，基速越低。
